## 🎯 关于本站

这里记录我在大语言模型、Agent、模型压缩与工程实践方面的学习过程。每篇笔记都尽量以具体项目源码或论文为起点，先实践、再归纳，把真实的实现细节沉淀为可复用的行业知识；涉及关键实现时，会同时给出源码拆解，讲清楚背后的原理。

本站使用与 [Hello-Agents](https://datawhalechina.github.io/hello-agents/) 相同的 docsify + Vue 主题搭建，支持暗黑模式、上一篇/下一篇、公式渲染、图表与字数统计。
